Project A · Backend service

Uptime Monitor

An HTTP uptime monitor that tracks uptime and p95 latency for the sites you point it at, and alerts you on Slack or Discord when one goes down.

Stack
Kotlin, Spring Boot, PostgreSQL, Docker, GitHub Actions
Highlights
  • Runs checks concurrently on a scheduler with a worker pool, so one slow target never delays the others.
  • A consecutive-failure state machine sends exactly one webhook alert per outage and one on recovery, which prevents noisy alerts.
  • Secured with SSRF protection and Spring Security login, with 40+ automated tests passing in GitHub Actions CI on every push. Deployed with Docker on Render.
